One sentence, at most 200 characters, pitching a bizarre startup idea that
sounds ridiculous at first glance but makes sense as a real business:
we rent professional debaters to win your Thanksgiving arguments.

Run it:

```sh
node main.ts
```

It writes the pitch deterministically to `/output/entry.txt`.
